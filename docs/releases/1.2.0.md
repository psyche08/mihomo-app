MihomoBox 1.2.0 simplifies App Proxy to a Team ID and signing-identifier policy, adds JetBrains to the defaults, removes Local DoH and keeps system DNS working when the DNS bridge listeners are interrupted.

- App Proxy routes by publisher: each entry is Team IDs, signing identifiers and code folders. Adding an application reads its Team ID and identifiers once; maintenance no longer scans, hashes or pins executables, and lease renewal reads no files.
- Helpers and command-line tools of listed identifiers (for example Codex helpers and Homebrew `codex`/`claude`) get path entries, so the CLIs that ChatGPT, Claude Code or a terminal start are diverted too. `mihomoboxctl app-proxy targets` reports which executables are matched by path.
- Application updates are picked up within seconds through FSEvents, with a 3-minute fallback pass. Rules are scaled per application and stay well below the NetworkExtension configuration limit.
- Fresh settings include a JetBrains Team ID default on listener 17970 next to OpenAI and Anthropic. Existing settings can add missing built-ins with Restore Team ID Defaults or `mihomoboxctl app-proxy policy add-defaults <node>`.
- Remove Local DoH (the loopback HTTPS DNS server, its profile, CA trust and DNS-mode switch). Legacy artifacts are cleaned up at daemon start. Global DNS is owned together with Enhanced TUN, and App Proxy DNS is resolved by the daemon over authenticated XPC.
- Work with DNS Proxy extensions such as MTTA: the 127.0.0.53 bridge is probed with a standard query, and both bridge listeners and the 127.0.0.1:1054 original-DNS listeners are supervised and rebound after an unexpected close. Previously a network change could leave system DNS failing for public names until the agent restarted.
- The menu shows the build number, for example "Version 1.2.0 (1200)".

Developer ID identity, bundle identifiers, Sparkle signing key and historical upgrade trust are unchanged. Releases are signed, notarized and stapled locally.
