MihomoBox 1.1.1 improves App Proxy stability and adds controls for everyday use.

- Add System Proxy and App Proxy switches to the menu bar. System proxy changes use authenticated daemon control, preserve previous settings, and restore owned settings when turned off.
- Show the Dock icon while the main window is open; remove it when the window is hidden. Clicking the Dock icon restores the existing window.
- Allow longer, bounded identity verification for Team ID scopes and distinguish authorization and provider timeouts.
- Add explicit migration from untouched legacy four-app presets to the OpenAI and Anthropic Team ID presets, preserving matching node selections and bypasses.
- Automate local provisioning-profile selection, freeze manual export mappings, recover interrupted release stages, and retry transient Apple timestamp-service failures.

Developer ID identity, application identifiers, Sparkle signing key, and historical upgrade trust remain unchanged. The release contains the locally signed, notarized and stapled arm64 App plus its signed Sparkle appcast.
